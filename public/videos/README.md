- `factory-hero.mp4` — used on Home + Landing video hero (recommended: 1920×1080, H.264, under 15–25 MB)
- Optional: `factory-hero.webm` for better compression
- Optional: `factory-poster.jpg` — first-frame poster image

Replace the demo remote video in `src/data/site.ts` → `heroMedia.fallbackSrc` once your local file is ready.
